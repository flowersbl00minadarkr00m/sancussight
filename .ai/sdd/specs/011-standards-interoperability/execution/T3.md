### Execution order and invariants

1. Local file size is checked before reading.
2. The T1/T2 pure validator or projector processes the transient input.
3. Current sanitized output remains in component memory.
4. A fixed snapshot is exact-shape validated before any repository write.
5. The latest equivalent snapshot for the same profile deduplicates without
   erasing intervening profiles.
6. Retention keeps the newest 20 per profile and no more than 100 globally.
7. A repository failure returns `unavailable`; it never invalidates the
   current in-memory result or mutates Feature 009/010 state.

The UI never promotes missing, unsupported, rejected, omitted, or imported
metadata to verified evidence. Alignment remains field-level metadata only.
The Statement remains unsigned and externally unverified.

### Edge cases and observable consequences

- Oversized or byte-mismatched OpenLineage files fail without persisting file
  bytes or unprojected values.
- Empty runtime evidence renders explicit missing/private-omission rows rather
  than synthesizing telemetry.
- Invalid or tampered Evidence Packets create no Statement or download claim.
- Unavailable IndexedDB leaves current previews visible and disables any false
  claim that history or clear succeeded.
- Clear targets only the dedicated Feature 011 database and resets only the
  current Feature 011 preview state.
- Long hashes and fixed public profile URLs wrap; the matrix scrolls inside
  its own bounded region; controls stack at the existing narrow breakpoint.

### Trade-offs and limitations

The implementation deliberately keeps three local operation paths in one
component because they share one approved Evidence Sources workflow and one
truth/privacy boundary. It does not introduce a generalized adapter framework
or dependency. Actual browser geometry, native file/download behavior,
IndexedDB inspection, focus movement, 320 CSS pixel behavior, and effective
200% zoom remain T4 acceptance work and are not claimed verified here.

Standalone `sdd-understanding` was unavailable in this installed skill catalog.
The required high-burden As Built evidence is therefore preserved in this
worker-owned execution record and handoff; orchestrator-owned
`understanding.md` was not edited.
