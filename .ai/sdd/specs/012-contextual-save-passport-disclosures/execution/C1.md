### Core Intuition and Invariants

The build boundary now has two independently checked layers. CSS states which
files may contribute Tailwind candidates; the verifier states the exact
source/config/static universe and observes the project modules Vite actually
loads. Generated evidence may remain anywhere else in the dirty repository,
but it cannot change candidate discovery or bundle bytes.

Pending feedback remains ephemeral presentation. `operationPhase` controls
only whether the strip renders its pending title/tone and disables its button.
The existing operation ref still guards duplicate writes; connection/session
state still owns dirty, conflict, permission, and durable source truth; and
the controller remains the sole persistence path.
