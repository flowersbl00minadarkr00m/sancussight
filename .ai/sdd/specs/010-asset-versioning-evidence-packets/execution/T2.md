### Background and intuition

- claim_class: `supporting-evidence`
- truth_label: `implemented`
- claim: The packet seam never copies a registry or result object and then
  sanitizes it. Each builder constructs a new exact object from approved
  fields, hashes private subject identity, and validates the completed object.
- source:
  `src/lib/evidence-packet.ts#buildAssetVersionEvidencePacket`,
  `src/lib/evidence-packet.ts#buildExitDrillEvidencePacket`

Before T2, versions and Exit Drill results were local typed values with no
portable packet boundary. After T2, both enter the same strict packet envelope:

```text
typed local source
  -> allowlisted projection
  -> hashed subject/reference fields
  -> exact recursive validation
  -> canonical digest excluding packetId/exportedAt
  -> validated local Blob download
```

### Core invariants

- claim_class: `supporting-evidence`
- truth_label: `verified`
- claim: Re-exporting one qualified payload with a different `exportedAt`
  retains one packet ID, while a qualified payload change changes the ID.
- source: `npm run test:feature010` exit 0; deterministic packet test.

- claim_class: `supporting-evidence`
- truth_label: `verified`
- claim: Asset subjects and Exit Drill item subjects are SHA-256 references;
  raw asset IDs, workflow IDs/names, asset names, and notes are absent.
- source: `npm run test:feature010` exit 0; asset and Exit Drill privacy tests.

- claim_class: `supporting-evidence`

- claim: Exact shape, supported versions, digest integrity, string and

- claim_class: `supporting-evidence`

### Edge cases, trade-offs, and consequences

- Unsupported objects, `undefined`, executable values, non-finite numbers, and
  non-plain prototypes cannot enter canonical JSON.
- Exit Drill workflow names and notes may be unsafe input because they are
  deliberately ignored; allowed target/status metadata must itself be safe.
- Arrays preserve canonical semantic order. Builders sort hash references,
  Exit Drill items, human decisions, and missing-evidence entries before
  digesting them.
- The packet is deliberately unsigned and supports no import or external
  verification. Its digest detects mutation but makes no authorship,
  compliance, standards, or trust claim.
- Missing Web Crypto or browser download capabilities returns an explicit
  failure and produces no claimed export.
