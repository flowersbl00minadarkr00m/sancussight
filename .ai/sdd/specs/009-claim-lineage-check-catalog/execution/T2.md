- IndexedDB uses an independent `sancussight-check-history` database and does
  not migrate or version existing connection/evidence stores.
- Auto-increment keys order locally recorded snapshots without adding a
  seventh persisted value field.
- All service operations are serialized per store instance. The bounded
  repository reads at most the retained global cap, favoring a small auditable
  implementation over a new runtime dependency.
- The history module adds no network route, analytics, raw-content history,
  provider action, upstream action, or schema migration.
