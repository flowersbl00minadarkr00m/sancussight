## As Built

The approved behavior is implemented as a two-step pure model:

1. `buildAssetCatalogIndex(assets, signals, today)` records bounded searchable
   text, per-asset facet values, counts, provenance class, missing counts, and
   dimension availability without modifying the source arrays.
2. `queryAssetCatalog(index, criteria, selectedAssetId?)` applies normalized
   search plus OR-within/AND-between facets and returns deterministic UI-ready
   summaries and selection/result state.

Recorded values supply owner, kind, lifecycle, and provider facets.
Portability uses the existing deterministic `SignalStatus` precedence
(`fail`, `warn`, `unknown`, `accepted`, `pass`). Evidence freshness uses
recorded evidence/coverage dates and applicable evidence-signal observation
dates with the existing `CHECKS_CONFIG.staleVerifyDays` threshold. When a
supported value cannot be established, the index uses
`CATALOG_MISSING_VALUE` and labels it `Missing / unavailable`; a whole
dimension with no non-missing values is `unavailable`.
