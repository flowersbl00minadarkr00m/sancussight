## As Built

The application shell now has one small navigation state addition:
`evidenceSourcesActive`. Normal view selection clears it; invoking Evidence
Sources sets it while returning the main view to Home. This keeps Evidence
Sources an action over the existing rail rather than inventing a second view
or duplicating source operations. The action waits for the view update, scrolls
the actual rail, expands its existing narrow-screen disclosure when needed,
and focuses an existing rail control.

Assets remains the T2 master-detail implementation. The shell applies a
specific Assets grid modifier that collapses the outer content/rail grid to
one column and hides only the existing rail while Assets is active. The T2
inner catalog/Passport grid therefore owns the available width. Choosing
Evidence Sources deliberately leaves Assets, making the existing rail visible
and operable again without changing its component or source authority.

Entry uses the existing mechanisms rather than new ingestion paths. The sample
still uses `#demo`; existing files/snapshots still use the established
connector/import flow; the compiler card is disclosure-only. Successful
non-landing routes now initialize or navigate to Assets so every successful
source path converges on the same canonical experience. Cancellation,
validation failure, confirmation, and no-silent-demo-fallback behavior remain
in the existing source controller/import code.

Exit Drill linking reuses the parent selection route and guards each result
against the active registry's canonical asset-ID set. The ontology test keeps
plain row labels. The ExitTest component's workflow and target remain local
state for its mounted lifetime; this ticket does not lift or duplicate that
state.

No approved requirement or design divergence was observed. The installed
skill catalog does not expose `sdd-understanding`, and this worker may not edit
the shared `understanding.md`; this structured As Built section is the durable
